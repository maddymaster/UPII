# Project Ember: Kestrin Firmware 2.0
Owner: Mei Chen. Sponsor: Daniel Okafor. Started: 2025-07-21

## Goal
Firmware 2.0 for the Kestrin hub: a rewritten Bluetooth pairing flow, support for the new radio module, and over-the-air updates in under five minutes.

## Out of scope
- New sensor types (planned for 2026).
- Changes to the Wrenfield dashboard beyond a firmware version column.

## Success measures
- Pairing a hub with a phone takes under 60 seconds for 95% of attempts.
- No more than 0.5% of hubs need a manual reset after the update.
